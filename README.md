# 🧠 Arithmo – Mental Math Game 🧠

🧠 A simple mental math game built with HTML, CSS, and JavaScript, packaged as an Android APK. Train your brain, one question at a time!

## 📥 Download & Install

### 📱 Method 1: Download APK Directly

1. Open the [Arithmo GitHub Repository](https://github.com/Vishal-dev-sketch/Arithmo-mental-math-trainer) on your Android phone.
2. Download the `arithmo.apk` file from the repository.
3. Open the downloaded file and install the app.
4. If prompted, allow installation from unknown sources.

### 💻 Method 2: Build APK Using Android Studio

1. Clone the repository:

   ```bash
   git clone https://github.com/Vishal-dev-sketch/Arithmo-mental-math-trainer.git
   ```

2. Open the project in Android Studio.
3. Go to **Build → Generate Bundle(s) / APK(s) → Generate APK(s)**.
4. Wait for the build to complete.
5. Find your APK in the `app/build/outputs/apk/` directory.
6. Transfer it to your Android phone and install it.

> 💡 Note: The repository must contain a properly configured Android Studio project to build the APK.

## 🧠 Features

- 🎯 **Three Difficulty Levels** – Easy, Medium, and Hard.
- ➕ **Math Operations** – Addition, subtraction, multiplication, division, and mixed operations.
- ⌨️ **Two Input Modes** – Keypad and multiple-choice answers.
- 🌙 **Light & Dark Themes** – Choose your preferred appearance.
- 📊 **Performance Tracking** – View your score and accuracy.
- ⏱️ **Time Tracking** – Check total time and average time per question.
- 💾 **Saved Settings** – Your theme and input mode are saved on your device.
